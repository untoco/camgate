# BLE-протокол camgate v1

Это контракт между прошивкой `camgate` и будущей реализацией в Onboard. Этот
репозиторий реализует BLE-периферию; код приложения Onboard здесь не изменяется.

## Обнаружение и подключение

| Поле | Значение |
| --- | --- |
| Роль camgate | BLE GATT peripheral / server |
| Имя в рекламе | `camgate` |
| Service UUID | `72269b15-38ee-4303-9255-003b4a9d2410` |

После отключения клиента camgate сохраняет последнее положение реле и снова
начинает рекламироваться. При новом подключении приложение должно сначала
прочитать характеристику состояния, затем включить уведомления. После подачи
питания camgate всегда запускается в зелёном состоянии: питание GoPro подано.

## Характеристики

| Назначение | UUID | Свойства | Формат |
| --- | --- | --- | --- |
| Команда | `72269b15-38ee-4303-9255-003b4a9d2411` | Write, Write Without Response | один байт |
| Состояние | `72269b15-38ee-4303-9255-003b4a9d2412` | Read, Notify | один байт |

### Команда

| Байт | Действие |
| ---: | --- |
| `0x00` | Подать питание на GoPro: выключить катушку, `COM → NC`, зелёный индикатор. |
| `0x01` | Отключить питание GoPro: включить катушку, `COM → NO`, красный индикатор. |
| `0x02` | Переключить питание GoPro. |

Команда другой длины или с другим значением игнорируется. После принятой команды
прошивка обновляет характеристику состояния и отправляет уведомление, если
клиент на него подписан.

### Состояние

| Байт | Значение |
| ---: | --- |
| `0x00` | Питание GoPro подано: катушка выключена, `COM → NC`, индикатор зелёный. |
| `0x01` | Питание GoPro отключено: катушка включена, `COM → NO`, индикатор красный. |

Нажатие кнопки Atom использует ту же логику, обновляет состояние и отправляет
уведомление подключённому клиенту. При перезапуске контроллер всегда начинает
в состоянии `0x00`: камера получает питание вместе с автомобилем.

## Граница текущей версии

В v1 нет аутентификации и сохранения состояния после пропадания питания. Она
предназначена для стенда и интеграции с Onboard до установки в автомобиль.
Автомобильная проводка, защита питания и политика BLE-доступа требуют отдельной
проверки до дорожного использования.
