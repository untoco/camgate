# Тест 01: кнопка Atom и реле

Единственный компонентный тест `camgate`. Он проверяет прямое соединение
`Atom Lite → Grove-кабель → Mini 3A Relay Unit (U023)` при питании Atom от USB.

## Логика

- При старте реле выключено: индикатор Atom зелёный, `COM` соединён с `NC`.
- Короткое нажатие встроенной кнопки Atom включает реле: индикатор красный,
  `COM` соединён с `NO`.
- Следующее короткое нажатие возвращает исходное состояние.

Скетч не подключается к автомобилю и не подаёт 12 В на контакты реле. Он
подтверждает только работу Atom, кнопки, индикатора, Grove-кабеля и реле как
единой стендовой сборки.

Запуск из корня репозитория:

```sh
./tools/pio.sh run
./tools/pio.sh run --target upload
```
